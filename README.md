# Text-Hash-Generator-
Hash Generator 🔐 -  A beginner-friendly Java application that generates cryptographic hashes using multiple hashing algorithms.


## Features
1) Generate hashes for any text input

2) Choose from:
    - MD5
    - SHA-1
    - SHA-256
    - SHA-512

3) Save generated hashes to a text file (`hash_results.txt`)

4) Simple command-line interface

5)  Safe cybersecurity project for learning cryptographic hashing


## Technologies Used

- Java
- MessageDigest (Java Security Package)
- FileWriter
- Scanner
